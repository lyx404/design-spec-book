Design Spec
Book

把产品意图、业务语义和视觉规则保存成一套可以被 Agent 继续读取的设计上下文。

01 / 安装

安装

npx skills add lyx404/design-spec-book -s design-spec-book -g -y

然后输入 $design-spec-book，为当前项目生成并同步六份设计声明。

02 / 使用说明

这样使用

01

第一次使用

为当前项目生成六份设计说明。

Use $design-spec-book to create the six design documents for this project.
02

同步项目变化

读取最新代码，只更新对应的设计事实。

Use $design-spec-book to sync the current codebase into the design documents.
03

调整设计规则

指定页面或组件，更新它的视觉和交互规则。

Use $design-spec-book to update the design rules for the checkout page.

03 / 它能做什么

为项目建立设计上下文

01

生成六份设计说明

按功能、业务、视觉、组件与页面模板分别整理。

02

从代码中同步内容

读取项目入口、组件、样式和 token，更新对应文档。

03

保留你的设计决定

只更新受管区块，你手写的内容始终保留。

04 / 六份声明

六份文档

每份回答一个问题
spec.md功能目标、状态流转和验收标准
domain.md业务对象、术语、风险和责任规则
craft.md排版、信息密度、反馈和动效工艺
design.md颜色、字体、间距、状态 token 和视觉规则
components组件职责、语义边界和可访问性
template页面类型、App shell 和响应式起点

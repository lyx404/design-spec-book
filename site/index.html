把产品意图、业务语义和视觉规则保存成一套可以被 Agent 继续读取的设计上下文。

01 / INSTALLATION

安装

使用短命令安装全局 Skill。安装完成后，在新的 Codex 对话中调用它。

npx skills add lyx404/design-spec-book -s design-spec-book -g -y READY

然后输入 $design-spec-book，为当前项目生成并同步六份设计声明。

02 / WHAT IT DOES

它保留什么

01

设计判断

把功能行为、领域语义、视觉系统和页面结构分开记录。

STRUCTURE
02

项目事实

扫描入口、路由、组件、样式和 token，只同步代码中可观察的事实。

FACTS
03

人的决定

受管区块之外的内容始终保留，自动同步不会覆盖你的设计判断。

PRESERVED

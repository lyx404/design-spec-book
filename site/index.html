02 / 使用说明

这样使用

01

第一次使用

为当前项目生成设计说明书。

使用 $design-spec-book，为当前项目生成设计说明书。
02

同步项目变化

读取最新代码，只更新对应的设计事实。

使用 $design-spec-book，读取当前项目的最新代码，同步更新相关的设计说明书。
03

调整设计规则

指定页面或组件，更新它的视觉和交互规则。

使用 $design-spec-book，按照当前最新的视觉与交互规则，更新设计说明书。

03 / 它能做什么

为项目建立设计上下文

spec功能目标、状态流转和验收标准
domain业务对象、术语、风险和责任规则
craft排版、信息密度、反馈和动效工艺
design颜色、字体、间距、状态 token 和视觉规则
components组件职责、语义边界和可访问性
template页面类型、App shell 和响应式起点
→ 自动更新代码变更静默期结束后，自动同步受影响的设计说明书
→ 手动更新用户发起同步请求后，立即检查代码变更并更新相关内容
→ 中间工作状态持续修改期间，仅记录待同步变更，不改写正式设计说明书
